# SA Ultimate (working name)

Scoring, line management and stats for the South African ultimate community. It is built for Android first, with a web version to follow, and is intended to replace the current Stall Count app.

- **Product spec:** https://claude.ai/artifact/3Qjhbogiimn1v5tHmGkfQt
- **Name candidates:** U-mzansi, Ubuntu Ultimate

## Data

Stall Count exports and screenshots live in the repo root as `.zip` files and are git-ignored because they contain personal information (POPIA). Don't commit them.
